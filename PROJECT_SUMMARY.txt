WHAT THIS PROJECT IS
────────────────────────────────────────────────────────────────────────────────
An automated forex day-trading system with:
- iOS SwiftUI app (ForexChance) — live at app/Sources/ForexChance/
- FastAPI Python backend — live at forex/backend/app/
- Hosted on Render (starter plan, free tier)
- Trades via OANDA v20 REST API (practice + live environments)
- JSON coding uses .convertFromSnakeCase / .convertToSnakeCase in Swift

────────────────────────────────────────────────────────────────────────────────
TRADING STRATEGIES (what the bot actually runs)
────────────────────────────────────────────────────────────────────────────────
1. EMA / Intraday (VWAP + RSI + EMA momentum) — THE CORE STRATEGY
   - Runs during London + NY sessions (session_filter = True)
   - Responsible for ~95% of profits in backtest
   - Calmar ratio: 3.40–4.06 when measured in isolation

2. London Open Breakout (london_open_breakout.py)
   - Asian-range breakout at London open, 07:00–10:00 UTC
   - Only on EUR_USD and GBP_USD
   - Currently ENABLED in config, generated no trades in recent 5000-bar tests

3. Opening Range Breakout / ORB (opening_range.py)
   - NY open 15-min range breakout, 13:15–17:00 UTC
   - Currently DISABLED (use_orb = False)
   - Backtested PF 0.97, Calmar -0.07 — net-negative on its own
   - BUT acts as a "protective gate" keeping EMA off bad NY-open bars
   - With ORB ON: overall Calmar 1.82; with ORB OFF: EMA Calmar 1.59

4. Order Block Reversal (order_blocks.py)
   - M15 reversal at last opposing candle before impulse, 07:00–20:00 UTC
   - Currently DISABLED (use_order_blocks = False)
   - Backtested PF 0.94, Calmar -0.12 — genuinely net-negative, no benefit

5. ICT Session Sweep (ict_sweep.py) — LIVE ONLY (requires M1 bars)
6. ICT Silver Bullet (silver_bullet.py) — LIVE ONLY (requires M1 bars)

Default pairs: EUR_USD, GBP_USD, USD_JPY, EUR_JPY, GBP_JPY

────────────────────────────────────────────────────────────────────────────────
BUGS FIXED
────────────────────────────────────────────────────────────────────────────────
1. 50 trades in 2.5 hours on live bot
   Cause: engine used day_sig.stop directly, bypassing min_stop_pips=12 clamp
   Fix: always compute stop_price from clamped stop_pips

2. All trades showing CLOSED +$0.00
   Cause: HWM close hardcoded realized_pl = 0.0
   Fix: extract P&L from OANDA orderFillTransaction response

3. Backtest win rate showing 3520%
   Cause: iOS BacktestStatsModel.winRatePct was doing winRate * 100 but
   backend already returns percent
   Fix: var winRatePct: Double { winRate } (no multiplication)

4. Backtest timeout
   Cause: _resample_to_m15(window_m5) called on every bar = O(n²)
   Fix: pre-compute M15 once before the loop, slice by timestamp

5. Breakeven sync mismatch
   Cause: backtest used hardcoded 1R trigger, live engine used cfg.breakeven_r
   Fix: backtest now uses stop_delta * cfg.breakeven_r

6. Win rate collapsing from 70% to 16% when spread changes from 0.5 to 1.0
   Cause: breakeven exits at entry+1pip, at 1.0 spread that nets 0 pips = loss
   Fix: be_buffer = (spread_pips + 1.0) pips so breakeven always nets +1 pip

7. ATR expansion filter toggle not affecting backtest
   Cause: BacktestRequest missing useAtrExpansionFilter field
   Fix: added to model and passed from ViewModel

Original (everything ON):          +45.9%  /  -25.9%  /  1.77
OB OFF, ORB ON, ATR ON:            +42.3%  /  -23.3%  /  1.82  ← best Calmar
OB OFF, ORB OFF, ATR ON, no gate:  +23.3%  /  -14.7%  /  1.59  ← best DD

Key insight: ORB (despite PF 0.97, barely negative) acts as a "gate" that
prevents EMA from taking bad entries in the NY opening range. Removing ORB
causes EMA to take 70 extra bad trades, worsening results. The time-gate
approach (blocking EMA 13:00–17:00 UTC) was too broad — it removed good
trades alongside bad ones.

API ENDPOINTS
────────────────────────────────────────────────────────────────────────────────

POST /api/autotrader/start           — start bot (credentials in body)
POST /api/autotrader/stop            — stop bot (leaves OANDA orders)
PATCH /api/autotrader/config         — live-tune config on running bot
POST /api/autotrader/backtest        — run historical backtest
POST /api/autotrader/reset-day       — reset daily trade counter + P&L
POST /api/autotrader/emergency-close — stop bot + close all positions
GET  /api/autotrader/learner-stats   — AI learner win-rate stats
